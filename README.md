## About

Android developer on a global corporate communication platform, covering voice, conferencing, chat, presence, and voicemail. I build features with **Kotlin** and **Jetpack Compose**, using **MVVM/MVI**, **Clean Architecture**, **Coroutines**, and **Flow**. I also investigate bugs from logs, write unit and instrumented tests, and work daily in English with QA, backend, DevOps, design, and product teams in Brazil, Greece, Romania, and India.
